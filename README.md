# Pink Portfolio

A responsive personal portfolio website built with HTML and CSS.

## About

This project is a simple and elegant personal portfolio with a soft pink visual style. It is designed to work well on mobile devices and larger screens.

The portfolio includes a profile image, a short introduction, social media links, and an email contact button.

## Features

- Responsive mobile-friendly design
- Custom pink and white color palette
- Profile section
- Short personal introduction
- Social media links
- Email contact button
- Simple HTML and CSS structure
- Easy to customize

## Project Structure

```text
    ├── instagram.png

```

## How to Use

1. Download or clone the project.
2. Keep `index.html`, `style.css`, and the `assets` folder in the same project folder.
3. Replace the profile image and links with your own information.
4. Open `index.html` in a browser to preview the website.

## Customization

You can edit the colors, fonts, text, images, and links directly in `index.html` and `style.css`.
